# Style Guide

This directory is a compatibility navigation surface for earlier Foundation
layouts. It does not define a separate domain or own a separate canonical style
guide.

Editorial governance belongs to the Foundation Documentation component. The
canonical candidate is:

- [DCSG-0001 - DunderCode Canon Style Guide](../documentation/DCSG-0001-canon-style-guide.md)

DCSG-0001 is currently a draft. Its requirements apply to DESys after approval;
consumer projects adopt them only through their own governance.
