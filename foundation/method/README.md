# Method

The Method collection describes how DESys turns engineering questions into
reviewable knowledge and validated implementations. Its canonical source is
DEM-0001.

The method is guidance for consumer repositories unless their own governance
explicitly adopts it. Teams may tailor activities according to risk, urgency,
and available evidence while preserving required project outcomes.

## Canonical Lifecycle

DEM-0001 defines seven iterative activities:

```text
Understand -> Model -> Design -> Specify -> Implement -> Validate -> Learn
     ^                                                            |
     `------------------------------------------------------------'
```

DEM-0001 currently defines these activities as an ordered lifecycle in which one
activity reaches its required outcome before the next begins. Learning may start
a new iteration of the lifecycle. Changes to that sequencing require a governed
revision of DEM-0001 rather than interpretation by this navigation file.
