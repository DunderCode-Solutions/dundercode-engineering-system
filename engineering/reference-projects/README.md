# Reference Projects

The Reference Projects Domain provides complete, production-oriented implementations that demonstrate how the engineering principles, standards, blueprints, templates, and tooling defined throughout the DunderCode Engineering System (DESys) should be applied in practice.

Reference Projects serve as canonical engineering examples that transform documented engineering knowledge into real software systems.

They provide a practical foundation for learning, adoption, validation, and continuous improvement.

---

# Purpose

The purpose of the Reference Projects Domain is to demonstrate how engineering knowledge is applied in complete software projects.

Rather than introducing new engineering concepts, reference projects integrate existing engineering assets into cohesive implementations that follow DESys principles from project initialization through deployment.

By providing production-quality examples, DESys accelerates learning, improves consistency, and reduces implementation uncertainty.

---

# What is a Reference Project?

A Reference Project is a complete software implementation built according to DESys engineering standards.

Unlike templates, which provide a starting point, reference projects demonstrate the complete engineering lifecycle of a real solution.

A reference project typically includes:

- Project structure.
- Engineering standards.
- Documentation.
- Testing.
- Automation.
- Deployment.
- CI/CD.
- Operational practices.

Reference Projects are intended to serve as canonical examples for future engineering work.
