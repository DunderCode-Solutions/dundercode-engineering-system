# 1. Purpose

This skill defines the **Problem Engineering (PE)** discipline adopted by the DunderCode Engineering System (DESys).

Within DESys, Problem Engineering is not the investigation of isolated incidents or the execution of Root Cause Analysis (RCA).

It is the engineering discipline responsible for discovering, modeling, eliminating and continuously preventing systemic operational weaknesses that generate recurring incidents.

Problem Engineering transforms operational failures into permanent engineering improvements.

---

# 2. Scope

Problem Engineering governs:

* Problem Identification
* Root Cause Engineering
* Systemic Weakness Analysis
* Known Error Engineering
* Permanent Corrective Actions
* Preventive Engineering
* Problem Intelligence
* Organizational Learning

Problem Engineering spans every recurring or high-impact operational problem.

# 17. Engineering Rules

Problem Engineering MUST:

* investigate systemic causes;
* preserve engineering evidence;
* eliminate recurring weaknesses;
* validate permanent corrective actions;
* institutionalize engineering learning.

Problem Engineering MUST NOT:

* confuse symptoms with root causes;
* stop after service restoration;
* blame individuals;
* discard investigative evidence;
* tolerate recurring preventable failures.
