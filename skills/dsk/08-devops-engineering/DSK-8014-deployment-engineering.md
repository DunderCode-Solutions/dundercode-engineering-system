# DSK-8014 | Deployment Engineering

# 1. Purpose

This skill defines the **Deployment Engineering (DE)** discipline adopted by the DunderCode Engineering System (DESys).

Within DESys, Deployment Engineering is not the execution of deployment scripts or infrastructure automation.

It is the engineering discipline responsible for transforming delivery-ready engineering capabilities into operational engineering capabilities through deterministic, reliable, observable and governed deployment processes.

Deployment Engineering transforms deployable software into operational software.

---

# 2. Scope

Deployment Engineering governs:

* Deployment Planning
* Deployment Automation
* Deployment Strategies
* Deployment Validation
* Progressive Delivery
* Rollback Engineering
* Deployment Observability
* Deployment Governance

Deployment Engineering spans every operational software release.

---

Deployment Engineering operationalizes engineering capabilities.

# 5. Deployment Engineering Model (DEM)

DESys adopts the **Deployment Engineering Model (DEM)**.

Every deployment SHALL define:

* Deployment Identifier
* Deployment Objective
* Deployment Strategy
* Deployment Target
* Deployment Window
* Release Artifact
* Validation Criteria
* Rollback Strategy
* Operational Constraints
* Deployment Evidence
* Deployment Status
* Traceability

The DEM defines the canonical deployment model adopted by DESys.
