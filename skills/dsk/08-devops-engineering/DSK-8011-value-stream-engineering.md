# DSK-8011 | Value Stream Engineering

# 1. Purpose

This skill defines the **Value Stream Engineering (VSE)** discipline adopted by the DunderCode Engineering System (DESys).

Within DESys, Value Stream Engineering is not the activity of drawing Value Stream Maps.

It is the engineering discipline responsible for designing, optimizing and continuously evolving the complete Engineering Value Stream that transforms engineering ideas into customer value through predictable, observable and continuously improving delivery systems.

Value Stream Engineering transforms engineering work into continuous value flow.

---

# 2. Scope

Value Stream Engineering governs:

* Engineering Value Streams
* Flow Engineering
* Constraint Engineering
* Bottleneck Analysis
* Flow Optimization
* Waste Elimination
* Engineering Throughput
* Continuous Flow Governance

Value Stream Engineering spans the complete Engineering Delivery System.

---

The EVSM defines the canonical value stream model adopted by DESys.

* optimize customer value flow;
* continuously eliminate waste;
* preserve end-to-end visibility;

Value Stream Engineering MUST NOT:

* create unnecessary waiting states;

* disconnect engineering from customer value.
