# DSK-8000 | DevOps Engineering Overview

# 1. Purpose

This document establishes the **DevOps Engineering** discipline adopted by the DunderCode Engineering System (DESys).

Within DESys, DevOps is not a collection of tools, pipelines or deployment practices.

It is the engineering discipline responsible for designing, automating, operating and continuously evolving the complete Engineering Delivery System that transforms engineering knowledge into operational software capabilities.

DevOps Engineering connects Software Engineering, Quality Engineering, Security Engineering, Testing Engineering, Platform Engineering and Operations Engineering into a continuously improving engineering ecosystem.

---

# 2. Vision

DESys defines DevOps Engineering as:

> **The engineering discipline responsible for continuously designing, integrating, delivering, operating and improving software systems through automation, observability, reliability and engineering governance.**

DevOps Engineering transforms software delivery into a continuously evolving engineering capability.
