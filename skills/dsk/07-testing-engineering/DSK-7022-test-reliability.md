# DSK-7022 | Test Reliability

# 1. Purpose

This skill defines the **Engineering Test Reliability (ETR)** discipline adopted by the DunderCode Engineering System (DESys).

Within DESys, Test Reliability is not limited to reducing flaky tests or improving execution stability.

It is the engineering discipline responsible for ensuring that the entire experimentation ecosystem consistently produces trustworthy, reproducible and reliable engineering evidence over time.

Engineering Test Reliability transforms experimentation into a continuously trusted engineering capability.
