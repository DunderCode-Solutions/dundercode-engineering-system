# 1. Purpose

This skill defines the **Engineering Test Orchestration (ETO)** discipline adopted by the DunderCode Engineering System (DESys).

Within DESys, Test Orchestration is not the simple sequencing of test executions.

It is the engineering discipline responsible for coordinating engineering experiments, execution environments, dependencies, resources, evidence flows and engineering decisions as an integrated experimentation ecosystem.

Engineering Test Orchestration transforms isolated executions into coordinated engineering knowledge.
