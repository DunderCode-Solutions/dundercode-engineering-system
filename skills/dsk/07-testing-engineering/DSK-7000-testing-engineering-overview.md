# DSK-7000 | Testing Engineering Overview

# 1. Purpose

This skill defines the **Testing Engineering** discipline adopted by the DunderCode Engineering System (DESys).

Within DESys, Testing Engineering is not a quality assurance activity, a debugging practice or a defect detection process.

It is the engineering discipline responsible for designing, executing and governing experiments that produce trustworthy evidence about the behavior of engineering systems.

Testing Engineering transforms experimentation into engineering knowledge.

---

# 2. Scope

Testing Engineering governs:

* Engineering Experimentation
* Behavioral Observation
* Evidence Production
* Test Design
* Test Execution
* Test Analysis
* Test Knowledge
* Testing Governance

Testing Engineering spans the complete engineering lifecycle.

---

Every testing activity SHALL define:

* Confidence

The ETM defines the canonical testing model adopted by DESys.

Testing Engineering MUST:

* define explicit testing objectives;
* formulate engineering hypotheses;
* execute reproducible experiments;
* produce trustworthy evidence;

* draw conclusions without evidence;

* lose engineering context;
* weaken evidence integrity.
