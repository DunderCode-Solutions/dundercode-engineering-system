# 1. Purpose

This skill defines the **Engineering Test Architecture (ETA)** discipline adopted by the DunderCode Engineering System (DESys).

Within DESys, Test Architecture is not the organization of test frameworks or source code.

It is the engineering discipline responsible for designing, governing and evolving the complete ecosystem that produces objective, repeatable and traceable testing evidence throughout the engineering lifecycle.

Engineering Test Architecture enables sustainable quality.

---

# 2. Scope

Engineering Test Architecture governs:

* Test Architecture Design
* Testing Layers
* Test Components
* Test Infrastructure
* Test Environments
* Test Data Strategy
* Evidence Architecture
* Architecture Evolution

Engineering Test Architecture supports every Engineering Testing activity.

* separate testing responsibilities;
* preserve deterministic execution;
