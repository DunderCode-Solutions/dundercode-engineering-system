# DSK-5000 | Security Engineering Overview

# 1. Purpose

This skill defines the **Secure Engineering Framework (SEF)** adopted by the DunderCode Engineering System (DESys).

Within DESys, security is not a development phase, operational activity or isolated discipline.

It is an engineering property that spans the complete engineering lifecycle, ensuring that business objectives, domain knowledge, architecture, design, software implementation, infrastructure and operations remain protected by consistent engineering security principles.

Security becomes part of engineering itself.

---

# 2. Scope

Secure Engineering Framework governs:

* Security Principles
* Security Policies
* Engineering Security Architecture
* Secure Engineering Practices
* Security Traceability
* Security Governance
* Engineering Security Knowledge

---

# 5. Engineering Security Model (ESM)

DESys adopts the **Engineering Security Model (ESM)**.

Engineering Security consists of:

* Security Policies
* Security Architecture
* Secure Design
* Secure Coding
* Secure Build
* Secure Deployment
* Secure Operations
* Security Governance

The ESM defines the canonical security model adopted by DESys.

# 6. Engineering Security Principles

Security Engineering SHALL follow these principles:

* Security by Design
* Zero Trust
* Least Privilege
* Defense in Depth
* Secure Defaults
* Fail Secure
* Continuous Verification
* Privacy by Design
* Traceable Security
* Deterministic Security

These principles SHALL guide every engineering decision.

* preserve integrity;
