# Engineering Guides

The Engineering Guides Domain provides practical guidance for applying the principles, standards, methodologies, and architectural concepts defined throughout the DunderCode Engineering System (DESys).

While specifications define what engineering assets are and governance domains define how they evolve, guides explain how to apply them in real engineering work.

The Guides Domain transforms engineering knowledge into practical engineering experience.

---

# Purpose

The purpose of the Guides Domain is to bridge the gap between engineering theory and engineering practice.

DESys contains a rich collection of standards, methodologies, architectural models, and governance processes.

Engineering guides demonstrate how these assets should be used together to solve real-world engineering problems.

By providing practical guidance, DESys improves consistency, onboarding, productivity, and engineering excellence.

---

# Guide Categories

Engineering Guides cover a broad range of practical topics.

Typical categories include:

| Category | Purpose |
|----------|---------|
| Getting Started | Introduces engineers to DESys concepts and workflows. |
| Tutorials | Demonstrates complete engineering workflows step by step. |
| How-To Guides | Explains how to accomplish specific engineering tasks. |
| Best Practices | Recommends proven engineering approaches. |
| Troubleshooting | Helps diagnose and solve common engineering problems. |
| Migration Guides | Supports the adoption of new standards and practices. |

Each guide focuses on practical application rather than theoretical specification.
