# Canon

The Canon collection contains the enduring engineering principles proposed or
adopted by DESys. Canon documents describe DunderCode's engineering philosophy;
they do not override consumer-project evidence or governance.

## Current Document

| Document | Status | Purpose |
| --- | --- | --- |
| [DEC-0001](DEC-0001-engineering-manifesto.md) | Draft | Defines the proposed DunderCode Engineering Manifesto. |

Draft canon content is review material. It becomes binding within DESys only
after lifecycle approval. A consumer project adopts it only through an explicit
project decision or policy.

## Relationship

```text
Canon principles
      |
      v
Engineering method
      |
      v
Standards and decisions
      |
      v
Implementations and evidence
```

The chain expresses intended traceability. Runtime behavior and approved project
decisions remain the authority for claims about a consumer system.
